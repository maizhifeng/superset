# 计划：新增"缤纷"明亮多彩主题 + 主题切换

## 目标
在现有"温暖纸本"主题基础上，新增第二个 **"缤纷"（明亮多彩）** 主题，用户可通过 AppBar 中的切换按钮在两者间自由切换，选择偏好持久化到 localStorage。

---

## 架构设计

### 主题切换机制
- 新建 `src/store/themeStore.ts`：zustand store，保存 `currentTheme: "paper" | "vibrant"`，持久化到 `localStorage`
- `src/theme/index.ts` 改为工厂模式：导出 `createPaperTheme()` 和 `createVibrantTheme()`，main.tsx 根据 store 动态传入 ThemeProvider
- 硬编码 CSS（scrollbar, selection, focus-visible）通过 `data-theme` 属性实现切换

### "缤纷"主题设计概念
以明亮、通透、多彩为关键词，与纸本主题的温暖克制形成鲜明对比：

- **底色**：极浅冷灰蓝 `#f6f8fc` → `#ffffff`，干净通透如玻璃
- **主色**：靛蓝 `#6366f1` → 科技感 + 信赖感
- **辅色**：品红 `#e11d8f`、青色 `#06b6d4`、琥珀 `#f59e0b`、紫罗兰 `#8b5cf6`
- **字体**：Plus Jakarta Sans（现代几何无衬线，干净有力）
- **卡片**：纯白纸面 `#ffffff` + 靛蓝顶部强调线 + 彩色阴影（靛蓝/品红调）
- **氛围**：现代 SaaS、数据驱动、能量感

## 缤纷调色板方案

```
bg default:    #f6f8fc (极浅灰蓝)
bg paper:      #ffffff (纯白)
surface main:  #ffffff
surface var:   #f1f3f8 (浅灰蓝)
primary:       #6366f1 (靛蓝)
primary light: #8b8ff5
primary dark:  #4f46e5
secondary:     #06b6d4 (青色)
error:         #ef4444 (红)
warning:       #f59e0b (琥珀)
success:       #10b981 (翠绿)
info:          #8b5cf6 (紫罗兰)
text primary:  #1e1b4b (深靛黑)
text secondary:#6b7280 (中性灰)
divider:       #e5e7eb
shadow:        rgba(99,102,241,0.08) → rgba(99,102,241,0.14)
```

### 视觉效果
- **背景**：纯色 `#f6f8fc`，干净无纹理
- **卡片**：纯白 `#ffffff` + 靛蓝顶部 3px 强调线 + 彩色阴影
- **悬停**：卡片上移 2px + 阴影加深（靛蓝调）+ 品红/青色微光
- **按钮**：渐变背景（靛蓝→紫罗兰）hover
- **输入框**：靛蓝聚焦环 + 品红光标
- **AppBar**：白色 + 底部靛蓝分隔线
- **登录页**：靛蓝→品红大渐变 + 浮动几何图形（圆形/菱形）
