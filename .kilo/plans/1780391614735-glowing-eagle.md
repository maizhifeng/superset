# 快捷钻取分析按钮 (Chips) 实现计划

## 需求

在日报/周报完成后，输入框上方显示 Chip 快捷按钮（自然语言分析方向），点击向模型发送钻取分析查询。

---

## 方案

### 核心思路

在 prompt 模板末尾追加 `DRILL_DOWN_SUGGESTIONS` 区块，AI 生成报告时输出 3-5 条钻取建议，前端解析并渲染为 Chip。

---

## 涉及文件及改动

### 1. `AiDrawer.tsx` (主要改动)

#### 1.1 `useAiChat` hook — 新增状态与逻辑

```typescript

const [suggestions, setSuggestions] = useState<string[]>([]);

// clear() 中重置

  // ... 现有逻辑
  setSuggestions([]);
};

// startNewChat / startDailyReport / startWeeklyReport 中重置

```

#### 1.2 `useAiChat` — 解析建议 (onDone)

在 `streamChat` 的 `onDone` 回调中提取 `DRILL_DOWN_SUGGESTIONS` 区块：

```typescript
const onDone = () => {
  const extracted = extractDrillDownSuggestions(full);
  setSuggestions(extracted);
};
```

**解析函数**：

```typescript
function extractDrillDownSuggestions(text: string): string[] {
  const marker = "DRILL_DOWN_SUGGESTIONS";
  const idx = text.lastIndexOf(marker);
  if (idx === -1) return [];

  const block = text.slice(idx + marker.length).trim();
  const lines = block.split("\n")
    .map(l => l.replace(/^[-*]\s*/, "").trim())
    .filter(l => l.length > 3);

  return lines.slice(0, 5);
}
```

注意：onDone 需要作为 `streamDirectChat` callbacks 中的新字段传入。目前 callbacks 有 `onText`, `onError`，需要添加 `onDone` 支持。

### 5. `uiInsight.ts` 的 `sendMessage` — 支持多轮对话

当前 `useInsight.sendMessage`（`useInsight.ts:76`）调用 `aiInsight.streamChat`，后者（`aiInsight.ts:252`）调用 `_streamLlmDirect("", message, ...)`，没有传历史消息。

需要：
- `streamChat` (aiInsight.ts) 增加 `history` 参数
- `insight.sendMessage` 收集 `insightText` 中的历史（或增加 `messages` 状态存储历史）

实际上 `useInsight` hook 没有维护 messages 数组，只有 `insightText` 字符串。需要改为维护 `messages` 数组以支持多轮。

**重构 useInsight**：

```typescript
interface InsightMessage {
  role: "user" | "assistant";
  content: string;
}

// 新增状态
const [messages, setMessages] = useState<InsightMessage[]>([]);

// sendMessage 中
const history = messages.slice(0, -1); // 排除当前渲染中的最后一条
const userMsg: InsightMessage = { role: "user", content: message };
setMessages((prev) => [...prev, userMsg]);

await streamChat(
  _sessionId, // 传 "" 或 sessionId
  message,
  { onText: ..., onReasoning: ... },
  signal,
  { ... },
  history, // 新增参数
);

setMessages((prev) => [...prev, { role: "assistant", content: fullText }]);
```

## 实施顺序

1. `AiDrawer.tsx` — 添加 `suggestions` 状态、解析逻辑、Chip 渲染、`onDone` 透传
2. `weeklyReportPrompt.ts` — 追加 DRILL_DOWN_SUGGESTIONS 区块
3. `dailyReportPrompt.ts` — 追加 DRILL_DOWN_SUGGESTIONS 区块
4. `aiInsight.ts` — `streamChat` 增加 `history` 参数透传
5. `useInsight.ts` — 重构成 messages 数组 + 传 history

---

## 不纳入范围

- Insight 变体不显示 Chip（仅日报/周报场景）
- 不解析旧对话（只在新的日报/周报生成后解析）
- 不涉及 SQL 执行（点击 Chip 发送自然语言给 AI）
