# 计划：数据集元数据 → 项目元数据（可配置设置项）

## 目标

将从 `/api/v1/dataset/{id}` 返回的数据集元数据 JSON 复制到 Starfly 项目元数据数据库表中，提供 API 读写和 UI 页面进行查看/编辑。

## 背景

- **前端**：`superset-frontend-new/`（React/MUI，运行在 localhost:9000）
- **数据库**：PostgreSQL `localhost:15432`，数据库 `sdk_data`（已通过 `postgres_query` 工具连接）
- **后端**：Superset Flask 后端处理 `/api/v1/...` 路由，可在其中添加新端点
- **Starfly**：独立的客户端（`starfly/client/`，端口 5173），代理 `/api` → `localhost:3001`。Starfly 后端服务器（3001 端口）尚未存在

## 方案

将功能直接添加到**现有的 Superset Flask 后端**和 **`superset-frontend-new` 前端**中，因为：
- Flask 后端已在运行并连接到 PostgreSQL
- 前端已有 DatasetEdit 页面和相关 UI 模式
- 无需从头搭建新后端服务器

"Starfly 后端数据库"将使用 `sdk_data` PostgreSQL 数据库（添加新表）。

---

## 步骤

### 第 1 步：创建数据库表

在 `sdk_data` 数据库中创建 `project_metadata` 表：

| 列名 | 类型 | 说明 |
|---|---|---|
| `id` | `SERIAL PRIMARY KEY` | 自增 ID |
| `dataset_id` | `INTEGER NOT NULL UNIQUE` | Superset 数据集 ID |
| `metadata_json` | `JSONB NOT NULL` | 完整数据集元数据 JSON（列、指标、描述等） |
| `created_at` | `TIMESTAMP DEFAULT NOW()` | 创建时间 |
| `updated_at` | `TIMESTAMP DEFAULT NOW()` | 最后更新时间 |

使用 `postgres_query` 执行 CREATE TABLE 语句。

### 第 2 步：创建后端 API 端点

在 `superset/datasets/project_metadata/api.py` 中添加新的 Flask 模块：

- `GET /api/v1/dataset/<id>/project_metadata` — 获取已存储的元数据
- `PUT /api/v1/dataset/<id>/project_metadata` — 保存/更新元数据

参考 `superset/datasets/columns/api.py` 中的现有模式（使用 `BaseSupersetModelRestApi`、`@expose`、`@protect`、`@safe`）。在应用中注册蓝图。

API 使用原生 SQLAlchemy 读写 `project_metadata` 表。

### 第 3 步：注册 API 蓝图

将新 API 添加到 `superset/datasets/__init__.py` 或应用的 API 注册处（例如 `superset/extensions/api.py`）。

### 第 4 步：创建前端元数据编辑器

在 `superset-frontend-new/src/pages/ProjectMetadata/` 中添加新页面：

1. **路由** — 在路由中添加 `/project-metadata/:datasetId`
2. **页面组件**（`DatasetMetadataEditor.tsx`）：
   - 从 Superset API（`/api/v1/dataset/{id}`）获取数据集元数据
   - 从新 API 获取已存储的项目元数据
   - 显示 JSON 编辑器（带语法高亮）
   - 保存按钮 → PUT 到新 API

### 第 5 步：连接 UI

- 在 DatasetEdit 页面（`superset-frontend-new/src/pages/DatasetEdit/index.tsx`）上添加按钮，导航到元数据编辑器
- 集成到现有的 PageSpeedDial 模式中

## 数据流

```
DatasetEdit 页面
    │
    ├── GET /api/v1/dataset/28  ← Superset API（已有）
    │
    └── [新 "Project Metadata" 按钮]
            │
            └── GET /api/v1/dataset/28/project_metadata  ← 新 API
                └── 从 `project_metadata` 表读取

            编辑表单 → PUT /api/v1/dataset/28/project_metadata
                └── 写入 `project_metadata` 表
```

## 已确认的决策

- **后端**：将端点添加到现有的 Superset Flask 后端（`superset/`）
- **初始同步**：手动 — 初始为空，提供"从 Superset 同步"按钮
- **编辑器**：原始 JSON 编辑器（带语法高亮）
- **API 端点**：`GET` 和 `PUT /api/v1/dataset/<id>/project_metadata`
