## Priority 1 — Fix Crashing / Broken Features

### 1.1 Redux Store Error
**Problem**: `Store does not have a valid reducer` console error. Empty `reducer: {}` causes Redux warning.
**Fix**: Add a noop root reducer or remove Redux entirely (all state uses React hooks/zustand pattern from starfly).

```ts
// Option A: Add noop reducer
const rootReducer = (state: any) => state ?? null;
export const store = configureStore({ reducer: rootReducer, middleware: ... });

// Option B: Remove Redux (preferred - follow starfly's zustand pattern)
// Remove <Provider store={store}> from main.tsx, delete store/index.ts
```

### 1.2 SQL Lab API Endpoint
**Problem**: `POST /sqllab/execute/` may not be the correct Superset endpoint. Need to verify endpoint.
**Check**: Look at `superset/sqllab/` API or use `POST /api/v1/sqllab/execute/`.
**Fix**: Update the endpoint URL in `src/pages/SqlLab/index.tsx` after verification.

### 1.3 Chart Data Fallback
**Problem**: `POST /chart/data` fallback still returns 400 for example charts (missing query_context).
**Fix**: Verify the POST body format matches `ChartDataQueryContextSchema`:
- `datasource: { id, type }` at top level
- `queries: [{ datasource, granularity, time_range, result_type }]`
- Remove `result_format` from top level (not in schema)

Also add a more descriptive empty state: "Chart data unavailable — save chart with query context" instead of "No cached data".
