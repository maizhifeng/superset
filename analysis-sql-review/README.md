## 一句话结论

现在 5 个专题共用一份 **50 列** 的 dataset 26（+海外 partner 38），每个专题实际只用 **10–18 列**。
方案是「每个专题一份只含自身字段的精简 SQL」：大陆侧 1 份 + 海外侧 1 份。
查询链路（`/api/v1/bi/chart/data`、比率拆分、跨库合并、缓存、快照、预热）不用改；
落地形态二选一：**A** 新数据集（改动最小，推荐）/ **B** 后端直接执行专题 SQL（可下推日期，收益更大）。
